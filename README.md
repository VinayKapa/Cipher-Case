# CipherCase: AI Detective Lab

An AI mystery investigation game. Build a case from a premise, inspect evidence, connect clues to suspects, ask branching interview questions, keep private notes, request hints, then make one final accusation. The API stores the solution and calculates the score.

## Project structure

- `apps/web` — React, Vite, TypeScript, Tailwind CSS client.
- `apps/api` — Express, TypeScript, Mongoose API and server-side Gemini integration.
- `packages/shared` — Zod contracts shared by both workspaces.
- `SPEC.md` — product and engineering specification.

## Local development

Use Node.js 20 or newer. Copy `.env.example` to `.env` and set `GEMINI_API_KEY`. Set `MONGODB_URI` for persistent case storage.

```sh
npm install
npm run dev
```

The client runs at `http://localhost:5173`; the API runs at `http://localhost:4000`. A Gemini API key is required to create custom and daily cases; every mystery is generated by Gemini. Generation errors are shown as retryable messages and never replaced with a built-in story. The default model is `gemini-3.5-flash-lite`, Google's stable Flash-Lite option for fast, high-throughput work; model availability still depends on Google's live service capacity and your project's rate limits. Without a MongoDB URI—or if Atlas is temporarily unreachable during local development—case records use in-memory storage and disappear when the API restarts. For persistence, use a local MongoDB or Atlas connection string. The development API compiles TypeScript before starting, so no platform-specific TypeScript loader is needed.

## API

- `GET /health`
- `POST /api/v1/cases` — `{ "premise": "...", "difficulty": "easy|medium|hard" }`
- `POST /api/v1/daily`
- `POST /api/v1/demo` — opens the explicitly selected, hand-crafted practice case without calling Gemini.
- `GET /api/v1/cases/:id`
- `POST /api/v1/cases/:id/discoveries`
- `POST /api/v1/cases/:id/links`
- `POST /api/v1/cases/:id/interviews`
- `POST /api/v1/cases/:id/hints`
- `POST /api/v1/cases/:id/notes`
- `POST /api/v1/cases/:id/accusations`
- `GET /api/v1/cases/:id/results`
- `GET /api/v1/share/:code` and `POST /api/v1/share/:code/play`

Before accusation, public case DTOs omit the culprit, hints, and solution. The client sends only action inputs; the server calculates all scoring from its stored case and activity. Cases are anonymous and expire after `CASE_TTL_DAYS` in MongoDB. The in-memory development adapter is ephemeral.

## Deployment

### MongoDB Atlas

Create a database user with access only to the CipherCase database, enable network access for the Render service, and keep the connection URI private. Use a database password with URI-reserved characters URL encoded.

### API on Render

The included `render.yaml` builds the shared package and API, starts the Express service, and uses `/health` for health checks. Set `MONGODB_URI`, `GEMINI_API_KEY`, and `CLIENT_ORIGIN` in the Render service environment. `CLIENT_ORIGIN` should be the exact Vercel origin. Never set the Gemini key as a `VITE_` variable.

### Web on Vercel

Import the repository with the included `vercel.json`. Set `VITE_API_BASE_URL` to the deployed API origin (without a trailing slash). The rewrite serves the Vite app for client-side routes. Add the Vercel origin to the API's `CLIENT_ORIGIN` allowlist.

Deployment is not complete until the public site can create a case, complete an investigation, and show a result against the deployed API. Credentials are intentionally not stored in this repository.

## Known scope

This initial release has no accounts or leaderboard. Shared links create an independent anonymous play session. The daily case is generated by Gemini for the current UTC date and reused while it remains stored. The home page also offers a separate hand-crafted demo case for practice when Gemini is unavailable; Gemini generation never silently falls back to it. Protect production services with provider rate limits and an appropriate Render plan.
